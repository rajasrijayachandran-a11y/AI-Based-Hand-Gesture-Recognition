# AI-Based Hand Gesture Recognition System

## Project Description
This project detects human hand landmarks using Python, OpenCV, and MediaPipe.

## Technologies Used
- Python
- OpenCV
- MediaPipe

## Features
- Detects hand landmarks.
- Supports detection of up to two hands.
- Uses a webcam to capture video.

## Requirements
Install the required libraries using:
pip install -r requirements.txt

## How to Run
Run the following command:
python main.py
